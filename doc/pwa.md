# PWA

Mis gastos web is provided with PWA support using *vite-plugin-pwa*.

## Configuration

Configuration is in [`/vite.config.ts`](/vite.config.ts).

Register is injected automatically (`injectRegister: 'auto'`). With this configuration, it is not necessary to add the following code to `main.tsx`:

```tsx
import { registerSW } from 'virtual:pwa-register'

const updateSW = registerSW({
  onNeedRefresh() {
    console.log('New version available')
  },

  onOfflineReady() {
    console.log('App ready for offline use')
  },
})
```

**Using automatic injection, the `registerSW.js` file will be automatically generated by  *vite-plugin-pwa* and imported in `/dist/index.html`. This file is not the service worker itself. Its job is to register the generated service worker (sw.js)**.

One disadvantage of using automatic injection is that the callbacks provided by `registerSW()`, such as `onNeedRefresh` and `onOfflineReady`, are not available for custom handling.

## Troubleshooting

**Check that the register is imported in  `/dist/index.html` (for automatic injection) :**

```html
<link rel="manifest" href="/manifest.webmanifest">
<script id="vite-plugin-pwa:register-sw" src="/registerSW.js"></script>
```

**Verify that the service workers (`/sw.js`) appears as the registered service worker through *DevTools → Application → Service Workers* (Chrome).**

**Test on real device, for example with Android:**

1. Connect the device
2. Forward the port from Android to the host:

    ```bash
    adb reverse tcp:5173 tcp:5173
    ```

3. On the Android device, open Chrome and navigate to http://localhost:5173
